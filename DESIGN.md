# SmartRead Echo Design System

## Core Value
SmartRead Echo is not a note dump. It is a reading companion that turns books into repeated recall.

The product flow is:
1. Find the right book quickly.
2. Capture what matters while reading.
3. Revisit it until it becomes your own thinking.

## Product Structure
- `書籍整理`: intake, metadata, shelf, progress.
- `Reading Lab`: timer, OCR capture, reflections, active reading workspace.
- `回聲複習`: spaced recall, favorite highlights, export, concept map, progression.

## Visual Direction
- Mood: warm editorial studio, calm desk, premium but not cold SaaS.
- Layout: app shell with a strong left rail and one dominant workspace on the right.
- Hierarchy: one primary task per panel, no walls of equal-weight cards.
- Motion: subtle hover lift only; avoid noisy animations.

## Typography
- Primary UI font: `Manrope`
- Display font: `Noto Serif TC`
- Rule: all major section titles and quote blocks use the serif display font.

## Color Tokens
- Background: parchment beige
- Panels: frosted ivory
- Ink: dark espresso
- Soft text: muted brown
- Cool accent: sage green
- Warm accent: amber copper

## Component Rules
- Sidebar items must show function, not marketing copy.
- Metrics should be short and numeric.
- Inputs should feel soft and tactile, never harsh or enterprise-heavy.
- Favorite quotes should feel collectible.
- Share surfaces should feel premium enough to screenshot.

## UX Rules
- A user should always know the next action in each section.
- Search by title is the default intake path.
- Progress updates should be direct and lightweight.
- OCR should live inside the reading workflow, not as a separate concept.
- Echo review should feel like a queue, not a content dump.
